# Media_Tools
Random tools built to help in media server programming that were too small to justify their own repos

## Tools
- **Audio Extractor**: wraps audio (or a video's audio) in a 16x16 black HAP .mov with 48k stereo PCM at a chosen frame rate. Downloadable Mac/Windows apps with ffmpeg built in are on the Releases page. See [Audio Extractor/README.md](Audio%20Extractor/README.md).
- **D3 Setlist Viewer**: single HTML page that turns a Disguise content table export into a searchable, readable list of content and tracks. Open it in a browser and load the table. See [D3 Setlist Viewer/README.md](D3%20Setlist%20Viewer/README.md).
- **ProxyMaker**: ffmpeg-based app that batch-creates half- or quarter-resolution proxies of a folder of media, formatted for Disguise. See [ProxyMaker/README.md](ProxyMaker/README.md).
- **Robocopy Frontend**: app for building Windows Robocopy commands (subfolders, purge, skip newer, exclusions) and copying them or saving them as a .bat script. See [Robocopy Frontend/README.md](Robocopy%20Frontend/README.md).
