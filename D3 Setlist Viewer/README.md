# D3 Setlist Viewer
Used to generate user-friendly and searchable content and track lists from Diguise's content table function

In Disguise, Generate a content table:
https://help.disguise.one/designer/content-management/generate-content-table#generating-a-content-table

Open this html file in a web browser, click the "Load .txt file" in the top right and load the content table. Enjoy the search and filtering capabilities. 
Also able to export CSV, TXT, and PDF from the filtered view.
